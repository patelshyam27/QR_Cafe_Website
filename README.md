# ☕ QR Cafe Management & Smart Dining System

A modern, responsive QR-based cafe management and table ordering website.

## 🌟 Highlights
- **Smart Dining**: Scan table QR code on a mobile phone to open the digital menu for that specific table.
- **Handcrafted Digital Menu**: Category filtering, real-time search, item customization, and add-to-cart.
- **Kitchen Display System (KDS)**: Real-time Kanban order board for chefs to manage cooking flow.
- **Table Reservations**: Advanced table booking with 24-hour overlapping slot prevention.
- **Executive Admin Dashboard**: Revenue metrics, order statistics, and customer reservation logs.
- **In-Browser Database Inspector**: Visual database explorer to inspect all tables and records directly in the web browser.

---

## 📂 Project Structure

- **`QR_Cafe_PHP_Website/`**: Complete web app built with **HTML5**, **Advanced CSS3**, **PHP 8.3**, and **SQL** (zero-configuration SQLite or XAMPP MySQL).
- **`QR_Cafe_Oracle_Website/`**: Oracle DBMS version with Flask and SQL scripts mapped to university DBMS syllabus practicals (Practicals 1 to 11).

---

## 🚀 Running the PHP Web App

1. Navigate to the PHP project:
   ```bash
   cd QR_Cafe_PHP_Website
   ```
2. Start the built-in server:
   ```bash
   php -S localhost:8000
   ```
   *(Or simply double-click `run.bat` on Windows)*
3. Open in browser: **http://localhost:8000**
